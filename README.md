A galaxy is not only an image.

It is a high-dimensional dynamical system observed through incomplete measurements.

A star contributes a point in a much larger space:

```text
POSITION
   ×
VELOCITY
   ×
CHEMISTRY
   ×
ORBIT
   ×
UNCERTAINTY
```

The interesting question is not simply **where the stars are**.

It is:

> **What history could have produced the structure we observe now?**
